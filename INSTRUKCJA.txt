Sygnał Dnia — poprawka 2.2 (na wersję 2.1)
1. Rozpakuj ZIP.
2. Repozytorium https://github.com/k0fa/sygnal-dnia → Add file → Upload files.
3. Wgraj newsroom.py oraz test_pipeline.py do katalogu głównego, zastępując pliki.
4. Commit changes. Poczekaj na zakończenie automatycznego uruchomienia.
5. Actions → Generate and publish news → Run workflow → main → Run workflow.
Nie zmieniaj generator.py z wersji 2.1, klucza, modelu ani workflow.

Co poprawiono:
- Odczyt tekstu z oznaczonych articleBody / article-body / article-content,
  także jeśli treść nie jest umieszczona w elementach p.
- Odczyt pasującego do adresu lub tytułu Article/NewsArticle z JSON-LD,
  tylko przy isAccessibleForFree=true. Nie pobiera płatnych treści z tej ścieżki.
- Przywrócono limit 16000 znaków na źródło; poprzednia poprawka przypadkowo
  zmniejszyła go do 8000 znaków.
- Każda próba pobrania ma wynik: adres, liczba słów (albo brak odczytu),
  metoda, przyjęto/pominięto i powód. Wyniki pozostają w podsumowaniu także
  po odrzuceniu całego tematu. Powielone źródła mają osobny powód pominięcia.
- Temat odrzucony przez próg 800 słów podaje rzeczywistą sumę przyjętych treści.
- Bez obniżania progów: 250 słów na źródło, 800 łącznie, dwie grupy wydawców,
  350–1000 słów artykułu. Pozostają weryfikacja faktów i limit 5 wywołań API.

Ograniczenia:
Dwie krótkie relacje nadal mogą nie spełnić wymagań; poprawka nie gwarantuje
artykułu w każdym cyklu. Nie dodano nowych źródeł ani płatnego wyszukiwania.
Metoda ekstrakcji nie dowodzi kompletności strony. Blokady, robots.txt i błędy HTTP
są respektowane i raportowane. Nie wykonano rzeczywistej generacji kluczem użytkownika.
Próba pobrania przykładowego adresu WP w tym środowisku zwróciła HTTP 404,
więc nie potwierdzono działania na tym konkretnym artykule.

Walidacja:
Testy lokalne Python 3.15; wyniki przekazane w odpowiedzi. Testy integracyjne
wymagają bibliotek instalowanych przez istniejący GitHub Actions.
