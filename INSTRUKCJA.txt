Sygnał Dnia — poprawka 2.9 dla instalacji 2.8

1. Rozpakuj ZIP.
2. GitHub: Code -> Add file -> Upload files.
3. Podmień w głównym katalogu generator.py, newsroom.py, test_pipeline.py.
4. Commit changes.
5. Actions -> Generate and publish news -> Run workflow -> main -> Run workflow.
Nie wybieraj Re-run starego uruchomienia po zmianie plików.

Zmiany:
- Jedna próba korekty dossier dla pustego risk_reason lub niepoprawnego cytatu.
- Model otrzymuje błąd walidacji, poprzednie dossier i niezmienione źródła.
- Skorygowane dossier przechodzi ponownie całą walidację.
- Brak dopisywania uzasadnień przez kod; brak akceptacji zmyślonych cytatów.
- Nieudana korekta kończy próbę, nie zapętla generacji.
- Obowiązkowa kontrola gotowego tekstu pozostaje aktywna.
- Limit pięciu zapytań API nie jest zwiększony. Korekta może zużyć zapytanie,
  które wcześniej było przeznaczone na kolejny temat. Jest wykonywana tylko
  gdy pozostaje budżet na korektę, tekst i wszystkie wymagane kontrole.
- Dla tematu wysokiego ryzyka konieczna pozostaje dodatkowa kontrola.
  Jeśli korekta ujawni wyższe ryzyko i zabraknie budżetu, publikacja jest wstrzymana.
- Logi zawierają powód próby korekty dossier.

Sprawdzono: 96 testów offline, wszystkie przeszły, oraz składnię plików.
Testy używają atrap API. Nie przetestowano rzeczywistego Gemini ani nie
wdrożono plików na GitHub. Korekta nie gwarantuje uzyskania poprawnej odpowiedzi.
