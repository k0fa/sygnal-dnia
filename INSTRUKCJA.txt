Sygnał Dnia — poprawka 2.7 (dla istniejącej instalacji 2.6)

1. Rozpakuj ZIP.
2. Repozytorium k0fa/sygnal-dnia -> Code -> Add file -> Upload files.
3. Wgraj do głównego katalogu, zastępując:
   generator.py
   newsroom.py
   test_pipeline.py
4. Commit changes.
5. Actions -> Generate and publish news -> Run workflow -> main -> Run workflow.
Nie wybieraj Re-run starego uruchomienia: używa poprzedniej wersji kodu.
Nie zmieniaj klucza API ani modelu.

Zmiany:
- Krótkie identyfikatory N1, N2... w zapytaniu, mapowane na oryginalne ID.
- Jawna grupa wydawnicza; różne serwisy Interii nie liczą się jako różni wydawcy.
- Selekcja szuka wspólnego wydarzenia, bez przedwczesnego wymagania długiego tekstu.
- Szczegółowe uzasadnienia braku tematu i odrzucenia grup, zamiast jednego ogólnego komunikatu.
- Rozpatrywanie poprawnych grup również po niepoprawnych; pomijanie powtórzonych grup.
- Kontrole dowodów i zasad publikacji pozostają aktywne. Brak pasujących źródeł
  nadal może skutkować brakiem publikacji; nie wymuszamy łączenia różnych wydarzeń.
- Limit pięciu wywołań API nie jest zwiększony.

Walidacja: 83 testy offline zakończone sukcesem; sprawdzono składnię plików.
Testy korzystają z atrap API, nie z rzeczywistego klucza Gemini.
Nie wdrożono plików bezpośrednio na GitHub.
Poprzednie logi nie zawierają odpowiedzi selektora, więc nie pozwalają ustalić,
czy model zwrócił pustą listę, czy grupy zostały odrzucone przez walidację.
Wersja 2.7 ujawnia tę różnicę w kolejnych uruchomieniach.
