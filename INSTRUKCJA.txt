Sygnał Dnia — poprawka 2.6

Wymaganie: istniejący projekt w wersji 2.5.
1. Rozpakuj ZIP.
2. Otwórz repozytorium k0fa/sygnal-dnia, zakładka Code.
3. Add file -> Upload files.
4. Przeciągnij trzy pliki: generator.py, newsroom.py, test_pipeline.py.
   Umieść je w głównym katalogu repozytorium, zastępując obecne wersje.
5. Commit changes.
6. Actions -> Generate and publish news -> Run workflow -> main -> Run workflow.
   Nie wybieraj Re-run starego uruchomienia: korzysta ono ze starej wersji kodu.
7. Otwórz podsumowanie nowego uruchomienia i sprawdź wynik generacji.

Zmiany:
- Uzupełniające linki pochodzą wyłącznie z treści artykułu, bez sekcji polecanych.
- Nie są automatycznie pobierane kolejne artykuły portali z linków w treści.
  Oryginalne materiały wybrane z RSS nadal są przetwarzane.
- Uzupełniające dokumenty z dozwolonych domen wymagają zgodności słów
  z tytułem i oznaczenia materiału źródłowego. To filtr heurystyczny:
  może pominąć poprawne źródło i nie gwarantuje pełnej zgodności tematycznej.
- Krótki, jednoznaczny cytat jest uzupełniany kontekstem z pobranego źródła.
  Parafrazy i zmyślone fragmenty nadal są odrzucane.
- Diagnostyka dowodów zawiera identyfikator faktu i źródła.
- Nie zmieniono wymagań weryfikacji oskarżeń ani innych tematów wysokiego ryzyka.

Walidacja: 74 testy offline zakończone sukcesem, w tym testy z atrapą API.
Nie wykonano testu z rzeczywistym kluczem Gemini ani wdrożenia na GitHub.
Brak wystarczających dowodów nadal może skutkować wstrzymaniem publikacji.
Nie zmieniaj sekretu GEMINI_API_KEY ani konfiguracji modelu z powodu tej poprawki.
