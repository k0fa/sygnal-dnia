Sygnał Dnia 2.12 — wybór tematów

Dla zainstalowanej wersji 2.10 (bez diagnostyki 2.11).
Rozpakuj ZIP. W GitHub wybierz Code -> Add file -> Upload files.
Podmień tylko newsroom.py w głównym katalogu i zapisz Commit changes.
Uruchom Actions -> Generate and publish news -> Run workflow -> main.

Zmiana: instrukcja selekcji wymaga przeglądnięcia wszystkich kandydatów
i ustawienia możliwych do opracowania tematów mniej ryzykownych przed
wojną i oskarżeniami. To priorytet wyboru, nie zakaz tych kategorii.
Kontrole dowodów i tematów wysokiego ryzyka nadal obowiązują.
Nie zwiększono limitu zapytań. Działanie zależy od wiadomości w RSS
i odpowiedzi modelu; nie gwarantuje publikacji w każdym cyklu.
Nie zmieniaj klucza API ani działającego modelu.

Zmiana dotyczy instrukcji dla modelu. Sprawdzono składnię Python.
Nie wykonano testu z rzeczywistym API.
